# 拉卡拉屏显设备逆向资料

本仓库记录一台 EC600U-CN 屏显设备的原厂固件逆向、接口及实机验证结果。资料截至 2026-10-09。目的是让开发者不阅读 QDisplay 实现，也能独立编写固件和电脑端程序。

**本项目禁止商用，仅限个人使用。** 未授权任何贩卖此商品的商家。商家授权及举报声明见[仓库 README](../README.md#使用限制与商家授权声明)；第三方内容仍遵循各自许可证。

| 入口 | 内容 |
|---|---|
| [逆向资料索引](reverse/README.md) | 引脚、原厂/当前核心地址、ABI、启动和刷写、显示、音频、完整传输协议 |
| [硬件映射](reverse/HARDWARE.md) | 每个信号所在的物理脚、软件编号及验证程度 |
| [不确定项](reverse/UNCERTAIN.md) | 印刷小液晶屏和查询键地址不确定；排线问题使实机结果无法作为反证 |
| [证据目录](reverse/EVIDENCE.md) | 公开反汇编、导入表、初始化字节、丝印照片及本地原始资料索引 |
| [QDisplay demo](demo/README.md) | 实际部署的原生 C / C# 源码、版本指纹、构建和刷写工具；BIN/MSI 从 Releases 下载 |
| [发布说明](demo/PUBLISH.md) | 源码与安装包分离、版本说明及创建仓库/上传 Release 的脚本 |

`demo` 是参考实现，现存闪烁/撕裂、Windows 音频采集问题如实列出。完整核心、原厂整机镜像、NV、用户媒体及历史会话不混进公开示例。所有原始逆向数据仍在本地 `reverse/private/`，默认被 Git 忽略；`junk/` 收纳旧环境和旧项目材料。

本机逆向和 demo 使用了不同版本：原厂 R05 用于恢复产品逻辑，当前 demo 在指纹固定的 R03 核心上运行。任何绝对地址必须连同版本和镜像哈希一起使用。
